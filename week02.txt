ls = list
ls -l = 파일들 생성된 시각정보
ls -a = 숨긴 거 (폴더에서 ... 옆에 보기 / 표시 / 숨긴항목 클릭)
ls -al

cat
cd 파일명 = 이동 
cd .. = 현재 폴더에서 상위 폴더로

git status = 현재 파일들 깃 여부 상태
git init = 이 파일을 깃이 관리하도록 지정 in 로컬
( .git 이라는 폴더가 또 생김)
(. / .. / week01.txt 였던게 . / .. / .git / week01.txt 로 변함)
